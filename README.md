# MedExchange (Node)

Node and TypeScript API for the MedExchange learning rebuild. `main` still holds the NestJS snapshot.

## Stack

- Node.js `http`
- TypeScript
- `tsx` for local runs

## Quick start

```bash
cp .env.example .env
npm install
npm run dev
```

Health check: `GET http://127.0.0.1:25121/health`
